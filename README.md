# Archivo de casos · Ithan Gael Hurtado

Portafolio personal en vivo: **https://ithangael.github.io**

Cada proyecto es un "archivo" con su propio mundo visual: al hacer scroll, la página cambia de colores, tipografía y animaciones según el sistema que construí.

| Archivo | Mundo |
|---|---|
| 01 · Reportes confidenciales | Documento clasificado con censura y sello |
| 02 · CyberSec Threat Monitor | Consola SOC con radar y feed en vivo |
| 03 · Pocholito | Cámara CCTV con visión nocturna y detecciones |
| 04 · NexAI Pro | Mini dashboard en vivo con el sistema de diseño del producto |
| 05 · Biblioteca TecMM | Ficha de catálogo con sello de préstamo |

- Bilingüe ES / EN (botón arriba a la derecha, se recuerda la elección).
- HTML, CSS y JavaScript puro: sin frameworks ni paso de compilación.
- Respeta `prefers-reduced-motion` y funciona en celular.
